Lançador Web
Como funciona: o TUPÃ prepara a estrutura completa da turma, incluindo ID/chamada, frequência e acertos. Depois, use a extensão de lançamento do navegador para transferir os dados para o sistema institucional. O TUPÃ não precisa abrir nem alterar o sistema externo diretamente.

2. Conferência antes do lançamento

Confira os dados que serão transferidos.

Pronto para conferir
Importante: todos os alunos da turma são mantidos, inclusive os que estão sem resultado. O ID/chamada é usado na identificação do aluno e a matrícula não participa da transferência.
Recortes por bloco: Bloco 01 — Português Q01–Q20; Bloco 02 — Geografia Q01–Q15 / História Q16–Q30; Bloco 03 — Matemática Q01–Q20; Bloco 04 — Inglês Q01–Q10 / Arte Q11–Q20 / Educação Física Q21–Q30; Bloco 05 — Física Q01–Q15 / Química Q16–Q30; Bloco 06 — Biologia Q01–Q15 / Sociologia Q16–Q23 / Filosofia Q24–Q30. No sistema institucional, cada recorte é renumerado a partir da questão 01.
