# ScoreView V10.9 — Limpeza do estado da correção

- Limpa a foto, URL blob, input file, resultado e revisão após salvar uma correção.
- Limpa o aluno selecionado após o salvamento para impedir reaproveitamento do aluno anterior.
- Ao escolher uma nova foto, o resultado anterior é descartado.
- Ao trocar manualmente de aluno, o resultado anterior é descartado para evitar associação cruzada.
- Mantém turma, bloco e gabarito para agilizar a próxima correção.
- Scanner/backend de leitura não foram alterados.
